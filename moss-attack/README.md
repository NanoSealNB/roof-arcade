# Moss Attack - NanoSeal NB

## How to Test Locally
```bash
cd moss-attack && python3 -m http.server 8080
```

## How to Deploy
Upload the `moss-attack` folder to `public_html/` on shared hosting.
Live at `https://nanosealnb.ca/moss-attack/`

## Difficulty Configuration
All gameplay constants in the `CONFIG` object at the top of `game.js`.
