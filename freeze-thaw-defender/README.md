# Freeze-Thaw Defender - NanoSeal NB

## How to Test Locally
```bash
cd freeze-thaw-defender && python3 -m http.server 8080
```

## How to Deploy
Upload the `freeze-thaw-defender` folder to `public_html/` on shared hosting.
Live at `https://nanosealnb.ca/freeze-thaw-defender/`

## Difficulty Configuration
All gameplay constants in the `CONFIG` object at the top of `game.js`.
